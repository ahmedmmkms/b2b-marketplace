# Scripts

This directory contains various scripts for project setup, deployment, and maintenance:

## Directory Structure
- `db/` - Database setup, migration, and management scripts
- `config/` - Configuration files and setup scripts
- `utils/` - Utility scripts for various purposes

## Database Scripts (`db/`)
- Schema creation and migration scripts
- Data seeding and reset scripts
- Database utility scripts

## Configuration Scripts (`config/`)
- Environment setup files
- Package management files (requirements.txt, package.json)

## Utility Scripts (`utils/`)
- General purpose utilities
- Testing utilities
