# Internationalization & RTL Guide

- Locales: `en` (default, LTR) and `ar` (RTL).
- Messages live in `messages/{lng}.json`. Keep keys scoped by domain (e.g., `home.hero.title`).
- Use `useTranslations()` for client components and `getTranslations()` for server components.
- Layout sets `<html lang dir>` and applies Inter (Latin) or Cairo (Arabic) fonts via CSS variables.
- RTL rules rely on logical properties (`margin-inline`, `padding-inline`, `text-align`) and Tailwind classes like `text-start`/`text-end`.
- Icons that imply direction are mirrored by toggling `scale-x-[-1]` for RTL.
- Dates/numbers should pass locale to `Intl.DateTimeFormat` or `Intl.NumberFormat`.

## Adding Messages

1. Update the English bundle.
2. Run localization review.
3. Translate to Arabic ensuring semantic accuracy.
4. Re-run `pnpm dev` or restart the server to reload messages.

## Routing Helpers

`libs/i18n/routing.ts` centralizes locale-aware routing helpers via `next-intl`. Always use `Link`/`useRouter` from that module to maintain locale segments.
