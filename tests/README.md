# Tests

This directory contains all test files organized by module:

## Directory Structure
- `core/` - Core components and utilities tests
- `identity/` - Identity management tests (accounts, users, authentication, RBAC)
- `catalog/` - Product catalog and vendor management tests
- `rfq/` - RFQ and quote management tests
- `orders/` - Order management tests
- `shared/` - Shared components and infrastructure tests

## Test Organization
Each module directory contains:
- Unit tests
- Integration tests
- Acceptance tests
- Production validation tests
